# 매점 바코드 조회 (MVP ①)

찍으면 상품명·가격이 뜨는 로컬 프로그램. **설치 불필요 — `index.html` 하나가 전부.**

## 쓰는 법 (매점 노트북)
1. `index.html`을 노트북에 복사 → **더블클릭**(크롬/엣지 등 아무 브라우저).
2. USB 바코드 스캐너 꽂기 (드라이버 불필요, 키보드처럼 동작).
3. **계산·조회** 탭에서 바코드를 찍는다.
   - 등록된 상품 → 상품명·가격 크게 표시 (딩동 소리).
   - 처음 보는 바코드 → **즉석 등록** 창(상품명·가격 입력) → 저장하면 다음부터 바로 뜸.
4. **상품관리** 탭: 등록 상품 검색·수정·삭제·직접 추가.
5. **백업** 탭: 가끔 **백업 파일 저장**(JSON) 눌러 보관. 노트북 바꾸면 **백업 불러오기**로 복원.

## 중요
- 데이터는 **그 브라우저에 저장**됨. 브라우저 데이터를 지우거나 노트북이 바뀌면 사라지니 **주기적 백업 필수**.
- 인터넷·서버 불필요, 완전 오프라인.

## 로드맵
- ✅ ① 조회 + 즉석등록 + 상품관리 + 백업  ← 현재
- ⬜ ② 여러 개 찍어 장바구니 합계·거스름돈
- ⬜ ③ 판매기록(일별 매출 집계)
- ⬜ (선택) 재고 차감·부족 알림
