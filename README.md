편의점처럼 **바코드 찍어 계산**하는 프로그램. 수동 계산 탈출용. **설치 불필요 — `index.html` 하나가 전부.**
(실제 카드 승인은 기존 카드단말기로. 이 앱은 금액 계산 + 매출 기록.)

## 기능 (P0 — 검증 완료)
- **계산**: 바코드 스캔 → 장바구니 자동 누적 → 합계 → 결제(현금 거스름돈 자동 / 카드 / 외상) → 매출 기록
- **즉석 등록**: 처음 보는 바코드는 상품명·가격 물어보고 바로 담김
- **상품 관리**: 검색·수정·삭제 + CSV 일괄 등록(`바코드,상품명,가격`)
- **매출**: 오늘/이번주/전체 매출·건수·객단가 + 잘 팔린 상품 TOP + 최근 거래
- **백업**: 전체 JSON 백업/복원, 상품·매출 CSV 내보내기

## 쓰는 법 (매점 노트북)
1. `index.html`을 노트북에 복사 → 브라우저로 열기 (크롬 추천 → 주소창 ⊕ "앱 설치"하면 프로그램처럼).
2. USB 바코드 스캐너 꽂기 (드라이버 불필요).
3. **계산** 탭에서 상품을 찍는다 → 다 찍으면 **결제**(또는 스페이스) → 받은 돈 입력 → 완료.
4. 미리 상품을 넣으려면 **상품 → CSV 일괄 등록**, 아니면 그냥 팔면서 즉석 등록.

## 단축키
- 스캐너/숫자 + Enter = 담기 · **스페이스** = 결제창 · 결제창에서 Enter = 완료

## 주의
- 데이터는 **그 브라우저에 저장**. 노트북/브라우저 바뀌면 사라지니 **백업 탭에서 가끔 파일로 저장**.
- 실제 카드 결제 승인은 이 앱이 아니라 **기존 카드단말기**로.

## 로드맵
- ✅ **P0** 스캔→결제→매출기록→리포트 (로컬, 오프라인)  ← 현재, 검증 완료
- ⬜ **P1** 클라우드 자동백업·다기기 동기화 (Supabase)

- ⬜ **P3** 외상장부·손님 관리
