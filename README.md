## 📦 매장 배포 (인터넷 없는 곳) — 권장
`매점POS.html` + `매점POS_실행.bat` **파일 2개만 USB로 복사** → `.bat` 더블클릭.
- 라이브러리까지 파일 안에 내장(1.27MB) → **외부 요청 0건, 인터넷 0% 의존**
- 크롬 앱 모드로 열려서 주소창 없는 **프로그램 창**처럼 보임
- 재빌드: `node build-standalone.js`
- 설치·사용법은 `사용설명서.txt` (지인에게 그대로 전달)

## 🔌 (대안) URL로 쓰기
1. **인터넷 되는 곳에서 한 번만** https://kkt09123-hub.github.io/pos/ 접속 (폰 핫스팟도 OK)
   → 크롬 주소창 **⊕ 설치** 누르면 앱으로 설치되고 통째로 캐시됨
2. 이후 **인터넷 없이** 그 아이콘으로 실행 가능
3. **백업 탭 → 📁 데이터 파일 지정** — 이후 판매/상품 변경마다 그 파일에 **자동 저장**
   (브라우저 기록을 지워도 파일이 남음. USB에 지정하면 그대로 백업)
- 대안: `index.html` + `xlsx.full.min.js`를 **폴더째 USB로 복사** → 더블클릭 (인터넷 0% 의존)

## 재고 쓰는 법
- **판매**: 결제하면 재고 **자동 −1** (할 일 없음)
- **입고**: 계산 탭에서 **📦 입고**로 전환 → 물건 스캔 → **입고 완료** (재고 +N)
- **실사 보정**: 상품 탭 → **수정·재고** → 실제 수량 입력 (틀어졌을 때 리셋)
- **초기 세팅/일괄 수정**: 엑셀 양식(바코드·상품명·가격·**재고**)으로 한 번에

---


편의점처럼 **바코드 찍어 계산**하는 프로그램. 수동 계산 탈출용. **설치 불필요 — `index.html` 하나가 전부.**
(실제 카드 승인은 기존 카드단말기로. 이 앱은 금액 계산 + 매출 기록.)

## 기능 (P0 — 검증 완료)
- **계산**: 바코드 스캔 → 장바구니 자동 누적 → 합계 → 결제(현금 거스름돈 자동 / 카드 / 외상) → 매출 기록
- **즉석 등록**: 처음 보는 바코드는 상품명·가격 물어보고 바로 담김
- **상품 관리**: 검색·수정·삭제 + CSV 일괄 등록(`바코드,상품명,가격`)
- **매출**: 오늘/이번주/전체 매출·건수·객단가 + 잘 팔린 상품 TOP + 최근 거래
- **백업**: 전체 JSON 백업/복원, 상품·매출 CSV 내보내기

## 쓰는 법 (매점 노트북)
1. `index.html`을 노트북에 복사 → 브라우저로 열기 (크롬 추천 → 주소창 ⊕ "앱 설치"하면 프로그램처럼).
2. USB 바코드 스캐너 꽂기 (드라이버 불필요).
3. **계산** 탭에서 상품을 찍는다 → 다 찍으면 **결제**(또는 스페이스) → 받은 돈 입력 → 완료.
4. 미리 상품을 넣으려면 **상품 → CSV 일괄 등록**, 아니면 그냥 팔면서 즉석 등록.

## 단축키
- 스캐너/숫자 + Enter = 담기 · **스페이스** = 결제창 · 결제창에서 Enter = 완료

## 주의
- 데이터는 **그 브라우저에 저장**. 노트북/브라우저 바뀌면 사라지니 **백업 탭에서 가끔 파일로 저장**.
- 실제 카드 결제 승인은 이 앱이 아니라 **기존 카드단말기**로.
