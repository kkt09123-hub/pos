  매점 POS — 사용설명서 (인터넷 불필요)
═══════════════════════════════════════════

■ 설치
  1) "매점POS_배포" 폴더를 통째로 노트북에 복사하세요 (예: 바탕화면).
     폴더 안 파일 3개는 항상 같이 있어야 합니다.
       · POS.html            ← 프로그램 본체
       · 매점POS_실행.bat    ← 실행 아이콘  ★ 이걸 더블클릭
       · launch.ps1          ← 실행 보조 (건드리지 마세요)
  2) "매점POS_실행.bat" 을 더블클릭하면 프로그램 창이 열립니다.
     (바탕화면에 바로가기를 만들어두면 편합니다 — 우클릭 > 바로 가기 만들기)

  ※ 인터넷이 전혀 필요 없습니다. 설치·회원가입도 없습니다.
  ※ 파란 경고창("Windows의 PC 보호")이 뜨면 [추가 정보] > [실행]을 누르세요.
     (서명되지 않은 개인 제작 파일이라 뜨는 안내이며, 한 번만 하면 됩니다)


■ 바코드 스캐너
  USB 스캐너를 노트북에 꽂기만 하면 바로 됩니다. (설정 불필요)
  프로그램의 "계산" 화면에서 상품을 찍으면 자동으로 담깁니다.


■ 처음 쓰는 순서
  1) 계산 탭에서 상품을 찍습니다.
  2) 처음 보는 상품이면 창이 떠서 [상품명 / 가격 / 재고]를 묻습니다 → 입력 후 저장.
     → 다음부터는 찍기만 하면 바로 담깁니다. (상품이 저절로 쌓입니다)
  3) 다 찍었으면 [결제하기] → 받은 돈 입력 → [완료]  (거스름돈 자동 계산)
     · 카드로 받으면 [카드] 선택 후 완료 → 실제 카드 결제는 기존 카드단말기로.


■ ★ 가장 중요 — 데이터 파일 지정 (한 번만)
  [백업] 탭 → [📁 데이터 파일 지정] → 저장 위치 선택 (예: 바탕화면\매점데이터.json)
  → 이후 판매·상품이 바뀔 때마다 그 파일에 자동으로 저장됩니다.
  → 이렇게 해두면 브라우저 기록을 지워도 데이터가 안전합니다.
  ※ USB에 지정하면 USB가 곧 백업본이 됩니다.
  ※ 노트북을 바꾸면 [📂 파일에서 불러오기]로 그대로 복원됩니다.


■ 재고 관리
  · 판매하면          → 재고가 자동으로 줄어듭니다 (할 일 없음)
  · 물건이 들어오면    → 계산 탭에서 [📦 입고]로 바꾸고 찍기 → [입고 완료]
  · 숫자가 안 맞으면   → 상품 탭 → [수정·재고] → 실제 수량 입력
  · 상품 탭에서 재고 부족(3개 이하) 개수를 보여줍니다.


■ 엑셀로 한 번에 정리하기
  바코드를 손으로 칠 필요 없습니다. 순서는:
  1) 상품 탭 → [📤 엑셀로 내보내기]   (바코드가 이미 채워진 파일이 나옵니다)
  2) 엑셀에서 상품명·가격·재고를 편집하고 저장
  3) 상품 탭 → [📂 엑셀 불러오기]


■ 매출 확인
  [매출] 탭 → 오늘 / 이번주 / 전체 매출, 거래 건수, 잘 팔린 상품
  [📤 매출 엑셀로 내보내기] 로 파일 저장 가능
  ※ 카드 매출은 카드단말기에서도 확인되고, 이 프로그램은 현금까지 포함한 전체 매출입니다.


■ 문제가 생기면
  · 화면이 이상하다        → 창을 닫고 다시 실행
  · 데이터가 안 보인다      → [백업] 탭 → [🔗 연결 복구] 또는 [📂 파일에서 불러오기]
  · 상품을 잘못 등록했다    → 상품 탭 → [수정·재고] 또는 [삭제]
